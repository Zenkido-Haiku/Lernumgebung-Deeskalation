# Lernumgebung Deeskalation

Studentisches Entwicklungsprojekt von Pascal Anna bei Zenkido® im B.A. Bildungswissenschaft der FernUniversität in Hagen.

Eine asynchrone Vorbereitung auf praktische Deeskalationsübungen für pädagogische Fachkräfte. Der erste Stand enthält die Startseite; Lerninhalte, Zugangscodes und Ergebnisspeicherung werden anschließend entwickelt.

## Bildungswissenschaftlicher Kontext

- Modul 3A: medienpädagogische Betrachtung der Möglichkeiten und Grenzen digitaler Vorbereitung auf körperbezogenes Lernen.
- Modul 3B: Planung, Entwicklung, Durchführung und Evaluation der Lernumgebung mit einer kleinen Pilotgruppe.

Die Seite ist ein studentisches Projekt, kein offizielles Lernangebot der FernUniversität. Die konkrete Themenanerkennung wird separat geklärt.

## Vorschau

`index.html` im Browser öffnen. Keine Installation und kein Build erforderlich.

## Gestaltung

Logo und Farben orientieren sich an den offiziellen Webressourcen der FernUniversität. Herkunft und verwendete Farbwerte stehen in `DESIGN.md`. Das Hochschullogo bleibt von etwaigen späteren Code-Lizenzen ausgenommen.

Es werden in diesem Stand keine Teilnehmerdaten erhoben; eine Anmeldung ist noch nicht implementiert.
